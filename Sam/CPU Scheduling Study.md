# [[Projects/CPU Scheduling Study|CPU Scheduling Study]]

This study aims to simulate CPU scheduling, studying the difference between different scheduling algorithms.

### Core functions

##### Interpretate process information

Process information received from user will include process arrival time and service time. 

##### CPU-scheduling algorithms

CPU-scheduling algorithms that are  researchd in this study

##### Display decision making 

The program will display the process that is queued into the cpu.

##### Display a gantt chart and summary

A gantt chart and data summary will be displayed along with data such as individual, total and average completion time, turn around time and waiting time.

### Program Requirement

1. User can enter multiple list of processes
2. User can choose algorithm to simulate
3. User can observe scheduling step by step or jump straight to result
